# 观澜 · 对话与长期记忆工作台

一个 Codex 风格的**个人对话工作台**：新会话只切换话题，不重新创建助手；从持续交流中选择性记住用户明确表达的资料、偏好、目标和边界。

本目录是用户明确授权新增的独立 Demo。没有修改或恢复上级工作区的论文、存证文件及旧实现。

## 运行

macOS / Linux，Python 3.9+，仅标准库，无需 pip、Node 或前端构建。

在工作区根目录运行：

```bash
bash demo/run.sh
```

打开 **http://127.0.0.1:8787**。macOS 也可以双击 [启动观澜.command](启动观澜.command)。终端保持打开；Control-C 停止后重新启动，原有数据仍在。若同一数据目录已经有实例运行，第二个实例会拒绝启动。

指定其他端口或独立数据目录：

```bash
python3 demo/server.py --port 8789 --data-dir /绝对路径/独立数据目录
```

本服务只监听 `127.0.0.1`，不要使用项目根目录的 `python3 -m http.server` 替代。

## 先体验，再连接模型

### 无需密钥：本地记忆预览

默认是**本地规则预览，不是大模型**。界面、消息及记忆会真实落盘，但回复只展示实际提取与召回结果，不具备自然对话或通用问答能力。

1. 发出：`我叫小林，我是产品设计师。我喜欢喝咖啡，以后请回答简洁一点。`
2. 右侧出现带原文来源的记忆；可点击来源或修订查看。
3. 新建对话，问：`你还记得我吗？`——从另一会话召回真实记忆。
4. 发出：`我不再喜欢咖啡，改喝茶。`——旧饮品偏好被取代，修订历史仍可追溯。
5. 编辑或忘记姓名，再问 `我叫什么名字？`，被忘记的记忆及其关联历史不会再注入。
6. 暂停记忆后，自动记忆写入和长期记忆注入一起停止；已有条目不删除。

示例中的姓名和职业可以替换成你自己的信息。规则引擎只覆盖有限明确句式；不能识别不代表数据丢失，复杂表达可手动记录或连接模型。

### 接入真实模型

左下角 **个人工作台 → 模型与连接**：

1. 运行模式选“连接模型”。
2. 选择 DeepSeek、OpenAI、Ollama 或自定义 OpenAI 兼容端点。
3. 填基础地址、模型名和 API key，点击“保存配置”。
4. 点击“测试已保存连接”，成功后关闭设置即可对话。

- 支持 `POST /chat/completions` 流式 SSE；不支持 Anthropic 原生 Messages 或 OpenAI Responses 协议。
- 远程端点必须 HTTPS；本机 localhost / 127.0.0.1 允许 HTTP。
- key 仅服务端保存，浏览器只收到掩码；更换 provider 或 origin 不继承旧 key。不要在聊天里粘贴密钥。
- 真实模型模式会向所选服务发送当前消息、有界近期历史与相关记忆。记忆抽取还会发送当前用户输入及已有属性键目录，不额外发送无关记忆正文。
- 开启记忆可能每轮额外调用一次模型做抽取，产生 API 费用。本版没有费用账本或供应商 token 计费面板。
- 模型调用失败**不会静默改用本地回复**；未完成回答不会保存为成功对话。记忆抽取单独失败时，保留正常回答、仅采用保守规则，并显示提示。
- 不预置密钥，不借用 DeepSeek Harness 自身的模型配置。

## 功能

- 暖白三栏工作台：会话、对话、关于你的记忆；支持窄屏抽屉。
- 流式回答、安全 Markdown、代码块展示、Enter 发送 / Shift-Enter 换行。
- 会话新建、重命名、归档；所有会话属于同一用户与同一助手。
- 记忆类别：资料、偏好、目标、边界；可搜索、置顶、手动添加、纠正、忘记。
- 同属性采用稳定 key；新明确陈述取代旧版本，保留来源、版本和 superseded 关系。
- 手动纠正默认置顶，自动提取不能覆盖置顶事实。需要更新时取消置顶或再次手动编辑。
- 交流风格与 emoji 边界是跨问题的常驻偏好；其他事实按相关度召回。
- 新增对话与记忆在同一 SQLite 事务提交，附一条认知事件。
- 请求 ID 持久去重；客户端断流后可沿用原 ID 重试，不重复保存。
- 同数据目录进程锁 + 整轮单写者锁；正在思考时拒绝其他写操作，读快照仍可用。

## 记忆流程

```text
当前用户输入
  ├─ 相关记忆 + 最多8轮可用历史 → 模型/规则回复
  └─ 明确自我披露 → 保守规则 + 可选模型候选
                               ↓
                   来源逐字校验、类别/长度/敏感项准入
                               ↓
            对话 + 记忆修订 + 单条认知事件原子提交
```

自动提取不以助手回答为事实来源。引用、故事、提问、假设、明确“不记录”及敏感凭证等采用保守跳过；模型提取仍可能出错，应允许用户检查和纠正，不把它当成心理画像或确定事实推断器。

### 忘记的语义

忘记是**检索与未来上下文排除**，不是物理删除：

- 同属性全部历史版本不再检索。
- 原始来源轮、直接引用轮，以及经近期历史传递引用的后续轮均不再注入模型。
- 来源溯源会跨轮传递，即使最早来源已经离开最近8轮窗口，忘记仍有效。
- 原聊天原文与修订记录仍保存在本机供查看；供应商已收到的数据不可能通过本地“忘记”撤回。
- 保守排除关联轮可能减少当前会话的近期上下文。这是本 Demo 为避免旧信息重新流入而作的取舍。
- 用户后来重新明确提供同一信息，仍可形成新记忆。

### 上下文预算

每次最多6条相关记忆（内容及预留开销合计2400字符），最多8轮近期历史（12000字符），单条用户输入最多6000字符。固定系统提示与序列化封装另计。本版使用**字符预算**，不是模型分词器精确 token 预算；不声称已经证明论文中 token 级 I8。

## 数据与安全

运行数据默认位于本目录 `runtime/`：SQLite 保存对话、记忆、设置、密钥、幂等记录及审计元数据；目录权限0700，数据库0600。数据与浏览器测试配置均被 `.gitignore` 排除。没有应用级加密，当前操作系统账户仍能读取这些数据。

服务只提供明确列出的三个静态资源，不提供 runtime、源代码或目录下载；写接口校验 Host、Origin、JSON 类型与自定义请求头；响应带 CSP / nosniff。用户内容以文本节点渲染，不解释为 HTML。服务不支持多用户认证或公网部署。

近期上下文与记忆作为**用户级数据**提供给模型，不插入系统权限层；没有命令执行、文件编辑或自动联网工具。注入检测仅为启发式，不承诺消灭所有提示注入。

## 证明与不证明

本 Demo 展示真实的持久化对话、选择性记忆、跨会话召回、版本修订、逻辑遗忘和事务提交；并不是原归档实现的替代认证版。

**不证明**：真实供应商兼容性/账单（未使用真实key验收）、模型抽取准确率、长期人格成长、参数学习、90天墙钟运行、跨机迁移、TEE、防物理复制、合规级删除或完整 STAS I1–I8 合规。

审计链覆盖状态变更**元数据**，不提供链外公证，也不是全内容重放日志。它能检测未重算链的元数据篡改，不阻止持有数据库的人重写整条链。模型响应不承诺逐位重放。
