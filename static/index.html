模型与连接

本地预览可体验真实记忆保存，但不会调用大模型。模型调用失败时，不会悄悄切换为规则回复。

连接真实模型后，最近对话与相关记忆会发送至你配置的服务商。开启记忆时可能额外调用一次模型提取信息，产生额外 API 费用；暂停后停止长期记忆写入与注入。

密钥仅保存在服务端，不会回传明文。更换服务商或地址来源时，不会沿用旧密钥。
